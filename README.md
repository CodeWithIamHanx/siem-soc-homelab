# siem-soc-homelab
A virtualized Security Operations Center (SOC) homelab using Wazuh SIEM to ingest logs, detect anomalies, and document incident response workflows.
This repository contains the documentation, configuration files, and incident write-ups for a custom SOC homelab. Built to simulate enterprise-level threat detection, it utilizes Wazuh SIEM and Sysmon for live log ingestion, rule-based anomaly detection, and rapid incident triaging.
